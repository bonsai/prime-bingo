# PRIME BINGO

素数をテーマにした、ブラウザで遊べるミニゲーム集です。既存の素数・倍数学習プロトタイプを残しつつ、独立して遊べる2つのモードを用意しています。

## ゲームモード

### 1. 素数ハンター 🎯
- 画面内を動く数字をタップして素数を集めるアクションゲーム
- 黄金色の素数は +10 点、素数ではない数字は −5 点
- 60秒制限。時間とともに数字の生成頻度と移動速度が上がります
- 一時停止・リスタート対応

### 2. 素数ビンゴ 🎱
- 素数を使った5×5のビンゴカード
- 数字を順番に引き、呼ばれた数字をカード上でマーク
- 縦・横・斜めのラインをそろえてビンゴを目指します
- 新しいカードで何度でも遊べます

## 起動方法

- `index.html` をブラウザで開くと、2モードをそのままプレイできます。
- GitHub Pagesを使う場合は、リポジトリ設定の **Pages → Deploy from a branch → main / root** を選択してください。

## ファイル構成

- `index.html` — 2モードを切り替えて遊べる、依存なしのブラウザ版
- `src/PrimeBingo.tsx` — 元のReact版「倍数を消して素数を集める」プロトタイプ
- `prd.yaml` — 元プロトタイプの要件定義

## 技術方針

- 公開・お試し用の `index.html` は Vanilla HTML / CSS / JavaScript。ビルド不要
- 元のReact / TypeScript実装は学習ロジックの参照用として保持
- 素数判定はクライアントサイドで完結
- スマートフォンのタップ操作に対応
- アカウント・サーバー・外部ライブラリは不要
